Social Sales Dashboard

회계감사 영업 콘텐츠를 한 번에 기획하고 검토합니다.

LinkedIn, Threads, 네이버 블로그, Instagram용 초안을 플랫폼별로 나누고, Claude안과 GPT/Codex안을 비교해 선택하는 로컬 글쓰기 대시보드입니다.

Claude / GPT 비교 플랫폼별 초안 Instagram 캐러셀 사람이 최종 게시

무엇을 하나요

  • 영업 주제 추천
  • 공통 원고 작성
  • 플랫폼별 최종본 변환
  • 작성자 소개와 문의 정보 자동 반영

어디에 쓰나요

  • LinkedIn 전문가 관점 글
  • Threads 짧은 대화형 글
  • 네이버 검색형 블로그 글
  • Instagram 2~5장 캐러셀

중요한 원칙

  • 자동 게시하지 않습니다.
  • 최종 게시 버튼은 사람이 누릅니다.
  • 고객사례와 성과 수치는 만들지 않습니다.
  • 회사 자료를 외부에 올리지 않습니다.

GitHub Pages 공개 버전 안내

이 페이지는 외부에서 볼 수 있는 정적 미리보기입니다. 실제 로컬 대시보드는 Python 서버, Claude CLI, Codex CLI, Chrome CDP를 사용하므로 GitHub Pages에서 직접 실행되지 않습니다.
